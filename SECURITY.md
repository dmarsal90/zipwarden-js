# Security policy

ZipWarden exists to handle untrusted input, so vulnerability reports matter.

## Reporting a vulnerability

Please report it privately. Do not open a public issue or pull request.

Use GitHub's private reporting: go to the **Security** tab of this repository
and choose **Report a vulnerability**
(<https://github.com/dmarsal90/zipwarden-js/security/advisories/new>).

Include, if you can:

- the affected version or commit
- a minimal archive or script that reproduces the problem (describe it, or
  attach it to the private report)
- what an attacker gains, for example a write outside the destination or
  unbounded resource use

You can expect an acknowledgement within a few days. Once a fix is ready, the
advisory is published with credit to you, unless you prefer to stay anonymous.

## Supported versions

The project is in development and has no stable release yet. Fixes go to the
`main` branch until a first version is published.
